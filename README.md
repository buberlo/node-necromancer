# Node Necromancer

> Summon forgotten dependencies from your package.json and hear their warnings.

A CLI tool scans your project for unused, outdated, or cursed dependencies and gives each one a ghost state. You can summon a ghost to print a warning, or banish it with a safe pin or removal plan.

## Features
- Unused dependency ghost scanner
- Summon command prints ghost warning
- Banish command generates pin or remove plan
- Weekly ghost report in terminal

## Stack
- Node.js
- Inquirer
- Chokidar

## Getting started
```
npm install && npm link, then run node-necromancer scan, node-necromancer summon <pkg>, node-necromancer banish <pkg>, or node-necromancer report in a Node project.
```
